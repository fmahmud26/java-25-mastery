# How to drill this bank

## Session formats

| Time | Format |
|------|--------|
| 30 min | 2 Junior + 2 Mid from one category |
| 45 min | 1 Mid + 1 Senior scenario + follow-ups |
| 60 min | 1 Staff/Principal scenario; whiteboard trade-offs |

## Answering Senior+ well

1. Restate constraints (SLO, consistency, ownership).  
2. Give the expected mechanism, then the failure mode.  
3. Name metrics/tools you’d use.  
4. State what you’d **not** do.  
5. Offer a Principal framing (standard, migration, blast radius).

## Red flags interviewers notice

- Trivia without scenario judgment  
- “Just use synchronized / microservices / VT” with no bounds  
- Invented Java 25 features or wrong JEP status  
- No mention of visibility, pools, or idempotency when relevant  

## Mapping levels to roles

- Junior/Mid → IC implementation interviews  
- Senior → on-call + design within a service  
- Staff → multi-service standards and incidents  
- Principal → multi-year technical strategy in the answer
