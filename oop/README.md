# OOP — Object-Oriented Design (Java 25)

Scenario-driven OOP for **Senior → Principal** interviews: modeling, extensibility, coupling, and maintainability — not Animal/Dog tutorials.

**Standards:** [DEEP_LEARNING_STANDARD.md](../DEEP_LEARNING_STANDARD.md) · [MASTER_INSTRUCTION.md](../MASTER_INSTRUCTION.md)

## Study path

1. Types & lifecycle: [class](./class.md) → [object](./object.md) → [constructor](./constructor.md) → [this](./this.md) → [constructor-chaining](./constructor-chaining.md) → [initialization-blocks](./initialization-blocks.md)  
2. Encapsulation & immutability: [encapsulation](./encapsulation.md) → [immutability](./immutability.md) → [records](./records.md)  
3. Abstraction: [abstraction](./abstraction.md) → [interfaces](./interfaces.md) → [abstract-classes](./abstract-classes.md)  
4. Inheritance & dispatch: [inheritance](./inheritance.md) → [super](./super.md) → [method-overriding](./method-overriding.md) → [polymorphism](./polymorphism.md) → [method-overloading](./method-overloading.md) → [covariant-return-types](./covariant-return-types.md)  
5. Relationships: [association](./association.md) → [aggregation](./aggregation.md) → [composition](./composition.md)  
6. Modern domain tools: [sealed-classes](./sealed-classes.md) → [domain-modeling](./domain-modeling.md)  
7. Drill: [interview.md](./interview.md)
