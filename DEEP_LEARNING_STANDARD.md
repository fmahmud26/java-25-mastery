# Deep Learning & Real-World Scenario Standard

Second-pass quality bar for `java-25-mastery`. Binding summary: [`.cursor/rules/deep-learning-scenarios.mdc`](./.cursor/rules/deep-learning-scenarios.mdc).

## Goal

After a topic, you can say: *I know what it is, why it exists, how it works, when to use / not use it, and how it behaves in production.*

Reasoning > memorization. Scenario > cheat sheet.

## Learning story (major topics)

1. Problem  
2. Naive solution  
3. Why naive breaks  
4. Better solution (the concept)  
5. How it works (L1→L4 internals)  
6. Production scenario (≥2)  
7. Trade-offs + when **not** to use  
8. Failure scenario (symptom→fix→prevention)  
9. Interviewer mode (Basic→Principal)  
10. Principal Engineer decision
