# java.net Overview

Classic package: `Socket`, `ServerSocket`, `URL`, `URI`, `InetAddress`, `HttpURLConnection`.

Modern service calls: prefer `java.net.http.HttpClient`. Use `URI`/`URL` for addressing; sockets for custom protocols.
