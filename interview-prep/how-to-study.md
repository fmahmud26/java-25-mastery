# How to Study (Integrated)

## Principle

**Practice producing structured answers under time**, then fill knowledge gaps — not the reverse.

## Weekly plan (example)

| Day | Focus |
|-----|--------|
| Mon | Answer framework drill (3 questions, full spine) |
| Tue | Track study (one track hub) + 1 deep-dive |
| Wed | Coding patterns timed |
| Thu | Debug or architecture format mock |
| Fri | Rapid-fire 20Q + review misses |
| Sat | Full mock (45–60m) recorded |
| Sun | Light review / experiments |

## Session recipe (45 min)

1. 5 min — pick track + format  
2. 25 min — perform (speak aloud)  
3. 10 min — compare to linked depth material  
4. 5 min — write one “I used to skip ___ in the spine”  

## Using depth packs

When a mock exposes a hole (e.g. JMM), open the matching pack ([concurrency](./concurrency/), [jvm](./jvm/), …) and do **one** lens (internals or performance), then re-answer the same question with PCR-OTDR.

## Don’t

- Collect more questions than you can answer structured  
- Memorize Principal speeches  
- Skip Result/validation  
- Study only Junior trivia before Senior mocks
