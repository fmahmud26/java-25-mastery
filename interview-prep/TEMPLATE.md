# Topic Pack Template

Copy this folder structure for any chapter (e.g. `interview-prep/generics/`).

```text
interview-prep/<topic>/
├── README.md                 # dimension index + links to chapter notes
├── theory.md
├── implementation.md
├── internals.md
├── coding.md
├── performance.md
├── real-world-usage.md
└── interview-questions.md    # Level 1–4 sections
```
