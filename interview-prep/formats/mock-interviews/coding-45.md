# Mock: Coding (45 min)

## Setup

Interviewer (or you) picks one medium problem from [coding-problems](../../../coding-problems/) you haven’t done this week.

## Timeline

| Min | Move |
|-----|------|
| 0–3 | Problem + Context (constraints, examples) |
| 3–8 | Brute force + complexity (Options) |
| 8–12 | Optimized Reasoning + Trade-offs |
| 12–35 | Decision: code |
| 35–40 | Dry-run + edges (Result) |
| 40–45 | Complexity + follow-up aloud |

## Grading

- Asked clarifying questions?  
- Named brute before optimize?  
- Spoke invariant while coding?  
- Tested an edge without prompting?  

## Anti-memorization

Change a constraint mid-mock (“now n=1e7”) and adapt Decision.
