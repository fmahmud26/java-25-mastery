# Track: Coding Interviews

## What they test

Clarify → brute → optimize → code → complexity → tests. Pattern recognition under time. Communication while coding.

## PCR-OTDR mapping

| Spine | Coding move |
|-------|-------------|
| Problem | Restate + examples |
| Context | Constraints, n, edge cases |
| Reasoning | Invariant / why pattern fits |
| Options | Brute vs optimized |
| Trade-offs | Time/space |
| Decision | Implement optimized |
| Result | Dry-run + complexity + edges |
